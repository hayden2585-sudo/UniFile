Zero-config install, completely free and open source. Connect directly to Claude Desktop, OpenAI, LangChain, Cursor, or your custom LLM pipeline.

Connect Unifile to Claude Desktop, Cursor, or Windsurf by adding this configuration to your claude_desktop_config.json:

  "mcpServers": {
    "unifile": {
      "command": "python3",

        "-m",

      ]
    }

}

Native function calling for GPT-4o, Claude 3.5/3.7, and Gemini:

agent_dispatcher.py 
from openai import OpenAI
from unifile import UNIFILE_TOOL_SCHEMAS, execute_unifile_tool

client = OpenAI()

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Inspect and translate corrupted_invoice.pdf into Spanish."}],
    tools=UNIFILE_TOOL_SCHEMAS,
    tool_choice="auto"
)

# Dispatch tool call
for tool_call in response.choices[0].message.tool_calls:
    result = execute_unifile_tool(tool_call.function.name, json.loads(tool_call.function.arguments))
    print(f"Readability Score: {result['readability_score']}% (>=80% guaranteed)")
    print(result['cleaned_text'])

Plug directly into LangChain or LlamaIndex agent react loops:

langchain_agent.py 
from unifile.connectors.langchain_tool import UnifileTool
from langgraph.prebuilt import create_react_agent

# Instantiate Unifile read-only universal connector
unifile_tool = UnifileTool(preferred_language="en")

agent = create_react_agent(
    model="gpt-4o",
    tools=[unifile_tool]
)

result = agent.invoke({"messages": [("user", "Summarize confidential_spec.docx")]})
print(result)

One-line installation and zero-config CLI or Python usage:

Terminal & Python SDK 
# 1. Easy Install (Free, Open-Source)
pip install unifile-by-soniscorett

# 2. Command Line Usage
unifile corrupted_file.pdf --lang es --output clean.txt

# 3. Python SDK One-Liner
import unifile

# Reads any file format, heals corruptions, guarantees >= 80% readability:
clean_text = unifile.read("corrupted_contract.pdf", lang="en")
print(clean_text)
